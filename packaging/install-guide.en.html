MeetingScribe Install Guide

A macOS app that records meetings, transcribes them and writes the notes. Follow the steps in order — about 15 minutes. Once installed, Settings → Environment in the app shows whether each piece is ready.

1Install the app

Requires a Mac with Apple silicon (M1 or later) and macOS 13 or newer.

  1. Open MeetingScribe-x.y.z.dmg and drag MeetingScribe onto Applications.
  2. First launch: in Applications, right-click MeetingScribe → Open, then click Open again. The app is not notarized by Apple, so a plain double-click is blocked the first time. You only do this once.
  3. If right-click → Open is blocked too, run this in Terminal and open the app normally:
xattr -dr com.apple.quarantine /Applications/MeetingScribe.app

The first launch takes about 20 seconds; later launches are faster.

2Allow the microphone

The first time you press record, macOS asks whether MeetingScribe may use the microphone. Click Allow.

If you clicked “Don’t Allow” earlier: open System Settings → Privacy & Security → Microphone, turn MeetingScribe on, then restart the app.

3Install BlackHole 2ch (to record the other side)

The microphone only hears you. The other people in a call come out of your computer’s speakers, and recording them needs BlackHole, a free virtual audio device. Without it the recording contains only your own voice.

Option 1 (recommended): with Homebrew. If you don’t have Homebrew, install it first with the one-line command on brew.sh.

brew install --cask blackhole-2ch

Option 2: download the BlackHole 2ch installer from existential.audio/blackhole and run it.

Restart your Mac afterwards. BlackHole is a system audio driver and only appears in the next step’s device list after a restart. The installer asks for your password — that is expected.

4Create a Multi-Output Device (hear and record at once)

While recording, your computer’s sound has to go to two places: your speakers / headphones (so you hear it) and BlackHole (so the app records it). macOS’s built-in Multi-Output Device does exactly that.

  1. Open Audio MIDI Setup: Launchpad → Other, or search “Audio MIDI Setup” with Spotlight (⌘ Space).
  2. Click “+” at the bottom left and choose Create Multi-Output Device. (① below)
  3. In the list on the right, tick BlackHole 2ch and the speakers or headphones you normally use, e.g. the MacBook speakers. (② below)
  4. Tick Drift Correction on the BlackHole 2ch row so long recordings don’t pick up crackles. Leave the primary device at its default.
  5. Keep the default name “Multi-Output Device” — the app finds it automatically.

When you record, the app switches the system output to the Multi-Output Device and switches it back when you stop. You don’t need to switch anything by hand.

Want music apps not to pause when recording starts? Make the Multi-Output Device your default output (right-click it → Use This Device For Sound Output). Then starting and stopping a recording switches nothing. The catch: with the Multi-Output Device selected, the keyboard volume keys don’t work — use the volume slider in the app.

If you switch between speakers and headphones, tick both. While recording, the app mutes whichever one you aren’t using, so sound never plays from both.

5Install and log in to the AI CLI (for notes)

Polishing the transcript and writing the notes use the Claude (or Codex) command-line tool with your own account. Without it, recording and transcription still work — only the notes step can’t run.

  1. Install Node.js: download the LTS version from nodejs.org, or with Homebrew:
brew install node
  1. Install the Claude Code CLI:
npm install -g @anthropic-ai/claude-code
  1. Run claude once in Terminal, log in to your account when prompted, then quit it.
claude

If you use Codex instead, replace the two steps above with:

npm install -g @openai/codex
codex login

Then, in Settings → Common settings → AI models, set “Polish transcript” and “Notes / reports” to Codex.

Afterwards, click Test in Settings → Environment. “logged in and replying” means it works.

6ffmpeg (optional)

Only needed to import mp3, m4a and other non-WAV audio (e.g. phone recordings). Recordings the app makes itself don’t need it.

brew install ffmpeg

7Models download on first use

The speech models aren’t in the installer. Each downloads automatically the first time it’s needed, once. The app tells you what it is about to download and roughly how big before it starts.

WhenWhatSize
First “Transcribe” or notesChinese speech recognition, segmentation and punctuation models~2 GB
First live captions (English)English streaming recognition + translation model~1.7 GB
First live captions (Chinese)Chinese streaming recognition (+ the Chinese models above)~0.2 GB

Stay online during the download; progress may sit still for a while, which is normal. Keep at least 5 GB of disk free.

8Optional settings

  • Calendar linkage: pick today’s event before recording. The recording is named after it, and its attendees help the notes put real names on speakers. Needs Google Calendar connected to your Claude account; turn it on in Settings → Calendar linkage, which checks the connection first.
  • Hotwords: colleague names, project codenames and other proper nouns. They accumulate automatically after each set of notes; you can also add them under Settings → Common settings → Edit hotword list (restart the app afterwards).
  • Custom goals: “Custom goals ▾” on the recording page. Describe the output you want in one sentence (e.g. “list every requirement the customer raised”) and the AI expands it into a full prompt.

All of the app’s data lives in ~/Documents/meetingscribe/: settings, hotwords, recordings and generated notes, and logs.

Troubleshooting

The other side isn’t in the recording
① Check BlackHole is installed and you restarted afterwards; ② check the Multi-Output Device has BlackHole 2ch ticked; ③ open Settings → Environment and make sure the first two rows are green. The app also warns at the top if BlackHole is missing when you start recording.
I can’t hear anything while recording
The Multi-Output Device has no speakers or headphones ticked. Tick them in Audio MIDI Setup; Settings → Environment shows this row in orange.
The volume keys don’t work while recording
A macOS limitation of Multi-Output Devices. Use the “Output volume” slider on the recording page.
“cannot be opened” / “developer cannot be verified”
See step 1: right-click → Open, or run the xattr command.
Generating notes fails
Click “Test” in Settings → Environment and install or log in to claude / codex as it suggests.
Transcription sits at the start
The first transcription downloads ~2 GB of models first, which takes a few minutes on a slow network. It won’t happen again.
I need to report a problem
Logs are in ~/Documents/meetingscribe/logs/, one file per day — send the file for the day it happened.
