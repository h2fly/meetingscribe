MeetingScribe 安装说明

会议录音、转写、自动生成纪要的 macOS 应用。按下面的顺序做一遍，大约 15 分钟。 装好后打开 app，在 配置 → 运行环境 里能看到每一项是否就绪。

1 安装 app2 权限 3 BlackHole4 多输出设备 5 AI 命令行6 ffmpeg 7 模型下载8 可选设置 常见问题

1安装 app

系统要求：Apple 芯片（M1 及以后）的 Mac，macOS 13 或更新。

  1. 双击 MeetingScribe-x.y.z.dmg，把 MeetingScribe 拖到右边的 Applications。
  2. 第一次打开：在「应用程序」里右键 MeetingScribe → 打开，弹窗里再点一次「打开」。 app 没有经过苹果公证，直接双击会被系统拦下，这一步只需要做一次。
  3. 如果右键打开也被拦，在「终端」里运行下面这行，再正常打开：
xattr -dr com.apple.quarantine /Applications/MeetingScribe.app

第一次启动大约需要 20 秒，之后会快一些。

2允许麦克风权限

第一次点录音按钮时，macOS 会询问 MeetingScribe 能否使用麦克风，点 允许。

如果之前点了「不允许」：打开 系统设置 → 隐私与安全性 → 麦克风，打开 MeetingScribe 的开关，然后重启 app。

3安装 BlackHole 2ch（录制对方的声音）

麦克风只能录到你自己。会议软件里对方的声音是从电脑播放出来的，要靠 BlackHole 这个免费的虚拟声卡才能录下来。 不装它，录音里就只有你一个人的声音。

方式一（推荐）：用 Homebrew 安装。还没装 Homebrew 的，先按 brew.sh 首页的一行命令装好。

brew install --cask blackhole-2ch

方式二：到官网 existential.audio/blackhole 下载 BlackHole 2ch 的安装包，双击安装。

装完请重启电脑。BlackHole 是系统音频驱动，重启后才会出现在下一步的设备列表里。安装时会要求输入电脑密码，这是正常的。

4配置「多输出设备」（边听边录）

录音时，电脑的声音要同时送到两个地方：你的扬声器 / 耳机（你要听），以及 BlackHole（app 要录）。 macOS 自带的「多输出设备」就是做这件事的。

  1. 打开 音频 MIDI 设置：在「启动台 → 其他」里，或者用 Spotlight（⌘ 空格）搜索「音频 MIDI 设置」。
  2. 点左下角的 「+」，选择 创建多输出设备。（下图 ①）
  3. 在右侧列表里勾选 BlackHole 2ch 和你平时用的 扬声器或耳机，例如 MacBook 扬声器。（下图 ②）
  4. 在 BlackHole 2ch 那一行勾上 漂移校正，避免录音时间一长出现杂音。「主设备」保持默认即可。
  5. 名字保持默认的「多输出设备」，app 会自动找到它。

录音时 app 会自动把系统输出切到多输出设备，停止后再切回来，平时不需要手动切换。

想避免录音开始时音乐 App 被暂停？可以直接把「多输出设备」设为系统默认输出（右键它 → 将此设备用于声音输出）， 这样开始和停止录音时就不会切换设备。代价是：用多输出设备时，键盘上的音量键不起作用，要用 app 里的音量滑块调节。

如果你有时用扬声器、有时用耳机，可以把两者都勾上。录音时 app 会自动静音你当前没在用的那个，不会两边同时出声。

5安装并登录 AI 命令行（生成纪要用）

校对文字稿和生成纪要用的是 Claude（或 Codex）的命令行工具，用的是你自己的账号。不装的话，录音和转写照常，只是不能生成纪要。

  1. 安装 Node.js：到 nodejs.org 下载 LTS 版本安装；或者用 Homebrew：
brew install node
  1. 安装 Claude Code 命令行：
npm install -g @anthropic-ai/claude-code
  1. 在「终端」里运行一次 claude，按提示登录你的账号，登录完成后退出即可。
claude

用 Codex 的同事，把上面两步换成：

npm install -g @openai/codex
codex login

然后在 app 的 配置 → 常用设置 → AI 模型 里，把「校对文字稿」和「生成纪要」改成 Codex。

装好后，在 配置 → 运行环境 里点 测试连接，显示「已登录，能正常回复」就说明可以用了。

6ffmpeg（可选）

只有导入 mp3、m4a 等非 WAV 格式的音频（比如手机录音）时才需要。app 自己录的音不需要它。

brew install ffmpeg

7第一次使用会下载模型

语音识别模型不在安装包里，第一次用到时自动下载，只下载一次。开始下载前 app 会提示要下载哪些、大概多大。

什么时候下载什么大小
第一次「语音转文字」或生成纪要中文语音识别、断句、标点模型约 2 GB
第一次打开实时字幕（英文识别）英文流式识别 + 翻译模型约 1.7 GB
第一次打开实时字幕（中文识别）中文流式识别（+ 上面的中文模型）约 0.2 GB

下载期间请保持联网，进度可能会停留一段时间，属于正常现象。磁盘请预留 5 GB 以上的空间。

8可选设置

  • 日程关联：录音前选中今天的日程，录音按日程标题命名，参会人会交给纪要环节对上真实姓名。 需要 Claude 账号里已连接 Google 日历，在 配置 → 日程关联 里打开，打开时会先检查连接。
  • 热词：同事姓名、项目代号等专有名词。每次生成纪要后会自动积累，也可以在 配置 → 常用设置 → 编辑热词表 里手工添加，改完重启 app 生效。
  • 自定义目标：录音页的「自定义目标 ▾」，用一句话描述你想要的输出（如「列出客户提出的所有需求」），AI 会帮你扩写成完整的提示词。

app 的所有数据都在 ~/Documents/meetingscribe/：配置、热词、录音和生成的纪要、日志。

常见问题

录音里没有对方的声音
① 确认已装 BlackHole 并重启过电脑；② 确认多输出设备里勾选了 BlackHole 2ch；③ 打开 配置 → 运行环境，看前两项是否都是绿点。 开始录音时如果没找到 BlackHole，app 顶部也会提示。
录音时自己听不到声音
多输出设备里没有勾选扬声器或耳机。打开「音频 MIDI 设置」把它勾上；运行环境里这一项会显示橙色提示。
录音时键盘音量键不起作用
这是 macOS 对多输出设备的限制。录音期间请用 app 录音页上的「输出音量」滑块调节。
提示「无法打开」或「无法验证开发者」
见第 1 步：右键 → 打开，或运行那条 xattr 命令。
生成纪要失败
到 配置 → 运行环境 点「测试连接」，按提示安装或重新登录 claude / codex。
转写一直停在开头不动
第一次转写要先下载约 2 GB 的模型，网络慢时需要几分钟。之后就不会了。
需要把问题反馈给别人
日志在 ~/Documents/meetingscribe/logs/，按日期一天一个文件，把出问题那天的日志发过去即可。
